### 3. Step 3 — Hook recall floor

Commit: `57278e8`

**`mcp/recall.py`** (new file)

`hook_recall(query, top_k=3, min_confidence=0.85) -> list[dict]`

- Synchronous — no async, CLI-friendly
- Pre-filters the shard index to entries with `meta_tags.confidence >= min_confidence` before scoring; returns `[]` when nothing clears the bar
- Scoring: token-overlap + Jaccard blend × confidence × trust (mirrors `Huginn._local_retrieve`; includes `meta_tags.summary` in the searchable text)
- Returns summary headers only: `{shard_id, summary, confidence, score, guiding_question}` — no `conversation_history`, no `turns`, no `body`
- In-memory LRU cache keyed on `(sha256(query)[:16], top_k, min_confidence)` with TTL controlled by `NOVA_RECALL_CACHE_TTL` env var (default 300s)
- Falls back to `guiding_question[:200]` when `meta_tags.summary` is absent

| Test | Asserts |
