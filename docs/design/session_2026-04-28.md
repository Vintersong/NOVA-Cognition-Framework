### Step 3 — Hook recall floor

Commit: `57278e8`

**`mcp/recall.py`** (new)

`hook_recall(query, top_k=3, min_confidence=0.85) -> list[dict]`

- Synchronous, no async — CLI-friendly
- Pre-filters index to `meta_tags.confidence >= min_confidence` before scoring; returns `[]` when nothing clears the bar
- Token-overlap + Jaccard blend (mirrors `Huginn._local_retrieve`); includes `meta_tags.summary` in searchable text
- Returns summary headers only: `{shard_id, summary, confidence, score, guiding_question}` — no bodies
- In-memory LRU cache keyed on `(sha256(query)[:16], top_k, min_confidence)` with TTL from `NOVA_RECALL_CACHE_TTL` (default 300s)
